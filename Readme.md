# 📊 Pesquisa de Satisfação de Atendimento ao Cliente

Projeto desenvolvido em Python para coletar e analisar dados de satisfação de atendimento de uma empresa com 50 entrevistados.

---

## 📌 Sobre o Projeto

O programa realiza uma coleta individual de dados dos entrevistados (nome, idade e avaliação do atendimento) e, ao final da pesquisa, contabiliza e exibe estatísticas sobre as respostas recebidas.
